**SEQ PLN** is the primary scope for **121.905** whenever **121.730** is primed. It is also the primary scope for **119.905** unless **121.905**, **121.630**, and **121.730** are all primed. The layout uses the **GND aspect** (same family as [AA + AD](/ekch/aa-ad/) and [CLR DEL](/ekch/clr-del/)).

When **121.630** is offline, **121.905** also covers arrival apron. Use the manually selectable [Apron Arrival](/ekch/apn-arr/) scope for arrival actions; the arrival bays on SEQ PLN remain passive.

## Bay overview

| Bay | Strip type | Notes |
| --- | --- | --- |
| **Messages** | Messages | Coordination / free-text. |
| **Final** | Arrival locked | Locked. |
| **RWY ARR** | Arrival locked | Locked. |
| **TWY ARR** | `APN-ARR` | Locked in this scope. |
| **Startup (SEQ)** | Cleared | Active — same strip as Cleared in [CLR DEL](/ekch/clr-del/); SI transfer follows TSAT. |
| **Push back** | `APN-PUSH` | Matches Push back in [AA + AD](/ekch/aa-ad/). |
| **TWY DEP** | Departure | Departure taxi bay. |
| **Others** | Uncleared | Active — SEQ PLN can issue clearances directly. |
| **SAS** | Uncleared | Same uncleared family. |
| **Norwegian** | Uncleared | Same uncleared family. |

## Uncleared strips

**Others**, **SAS**, and **Norwegian** match [CLR DEL](/ekch/clr-del/) uncleared strips and are active so SEQ PLN can clear aircraft when needed.

## Startup (SEQ)

All cleared departures sit in **Startup (SEQ)**, sorted by TSAT with the earliest time at the bottom. A TSAT update automatically changes the order. Clickspots match Cleared strips in CLR DEL.

<Aside>
The SI box shows white when the strip is owned by SEQ PLN. When the aircraft calls for startup, click SI within the TSAT startup window to transfer it to the next controller.
</Aside>

The next logical route steps are:

- **Any G stand or APRON SOUTH stand:** GE 121.830 → the applicable tower.
- **W1, RI, RII, RIII:** GW 118.580 → the applicable tower.
- **Other stands:** AD 121.730 → the configured ground/tower route.

Unavailable steps are skipped. When consecutive steps are carried by the same primary, no self-transfer is created.
